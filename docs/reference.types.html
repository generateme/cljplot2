4  Types

Option cards name the type of each form an option accepts, and link here. This chapter says what each type is, with an example. Leaving an option out uses its default.

(ns reference.types
  (:require [notebook-utils :as nu]))

4.1 accessor

How a value comes from a row: a key such as :x, a function of the row such as #(* 2 (:x %)), or either wrapped in levels/categorical to treat numbers or dates as levels.

4.2 alignment

A pair [h v]: h is :left, :center or :right and v is :top, :middle or :bottom, e.g. [:center :middle].

4.3 annotation

A pair [accessor colour-scale-spec] that adds a strip beside a clustered heatmap: the accessor returns each row’s value and the spec sets the strip’s colour scale (nil for the default), e.g. [:group {:range :set2}].

4.4 bandwidth rule

A rule that picks the bandwidth from the sample: a fastmath selector, e.g. :nrd0 (R’s default) or :sj (Sheather-Jones).

4.5 bin rule

A rule that picks the number of equal-width bins from the sample: a fastmath method, e.g. :sturges or :freedman-diaconis.

4.6 boolean

Either true or false.

4.7 breaks

The bin edges: a vector of at least 2 increasing finite numbers, e.g. [0 10 20 50]. Values outside them fall in no bin.

4.8 colour

A solid colour, or :none.

4.9 colour range

Colours for a colour scale: a clojure2d palette name such as :tableau-10, a gradient name such as :viridis/viridis, or a non-empty sequence of solid colours such as [:white :darkred].

4.10 colour vision deficiency

A simulated deficiency: :protanopia, :deuteranopia, :tritanopia or :achromatopsia, or a pair [kind severity] of an -anomaly kind and a severity from 0 to 1, e.g. [:deuteranomaly 0.5].

4.11 count format

A format string for a whole number such as n=%d, or a function of the count that returns its text.

4.12 dash

How a line is dashed: a style name such as :dashed or :dotted, a vector of dash and gap lengths in pixels such as [5 3], or :none (also :solid) for a solid line.

4.13 data

Rows or columns: a sequence of maps, e.g. [{:x 1 :y 2} {:x 2 :y 3}], or a map of equal-length sequences, e.g. {:x [1 2] :y [2 3]}.

4.14 date or time

A java.time value: a date, a date-time, an instant or a time, e.g. (java.time.LocalDate/of 2024 1 31).

4.15 density kernel

The shape a density estimate puts at each value: a fastmath kernel name, e.g. :gaussian or :epanechnikov.

4.16 distribution

A fastmath distribution: a distribution object, or its name with optional parameters, e.g. [:normal {:mu 0 :sd 1}] or [:exponential].

4.17 fill pattern

A pattern drawn over a filled mark: a name such as :hatch or :dots, or a map such as {:kind :lines :angle 45 :spacing 6 :width 1}.

4.18 finite number

A number that is neither infinite nor NaN, e.g. -3.2.

4.19 font

A font name - the bundled DejaVu Sans Mono, an installed family or a logical font such as SansSerif - or a java.awt.Font.

4.20 fraction

A number from 0 to 1, both ends included, e.g. 0.3.

4.21 function

A Clojure function; its option says what it takes and returns, e.g. (fn [x] (* 2 x)).

4.22 functions

One function, or several with labels: a vector of functions (labelled 0, 1, …), a vector of [label function] pairs, or a map from label to function, e.g. [["sin" m/sin] ["cos" m/cos]].

4.23 gradient

A clojure2d gradient: a preset name such as :mpl/viridis, a list of colours such as [:white :steelblue], or a function of t from 0 to 1 that returns a colour.

4.24 interpolator

A fastmath 1D interpolation method such as :cubic or :monotone, or a function of the points’ xs and ys (and any parameters) that returns the curve as a function from x to y.

4.25 interval

Two finite numbers [lo hi] with lo below hi, e.g. [0 10].

4.26 malli schema

Any value malli accepts as a schema, e.g. [:int {:min 0}].

4.27 non-negative finite number

A finite number zero or greater, e.g. 0 or 12.

4.28 non-negative number

A number zero or greater, e.g. 0 or 2.5.

4.29 number format

A format string such as %.1f (see format), or a function of the number that returns its text.

4.30 open fraction

A number strictly between 0 and 1, e.g. 0.95.

4.31 overlap fraction

A number from 0 up to, but not including, 1, e.g. 0.5: the share of points two neighbouring intervals have in common.

4.32 padding

Two non-negative fractions of the data span [lo hi]: the room added at the low and the high end, e.g. [0.05 0].

4.33 palette

A clojure2d palette name such as :tableau-10, or a non-empty sequence of solid colours such as [:red :green :blue].

4.34 panel position

A place in the panel rather than in the data: [:panel f], a fraction f from 0 to 1 of the way from the low-value end, e.g. [:panel 0.5] - the middle. It doesn’t widen the axis.

4.35 point shape

A built-in shape character such as \o, a string - always drawn as text ("E", short for {:text "E"}; a file takes {:svg source}), or a map {:path svg-path}, {:text string}, {:svg source} or {:image image}.

4.36 position

A place on an axis in data units: a number, a java.time value, or a level (a string or keyword) on a categorical axis, e.g. 2.5 or "setosa".

4.37 positive finite number

A finite number greater than zero, e.g. 1.5.

4.38 positive integer

A whole number from 1 up, e.g. 200.

4.39 positive number

A number greater than zero, e.g. 0.5.

4.40 quantile bins

Bins with edges at quantiles of the values: {:quantiles q :estimation e}, e.g. {:quantiles 4}. q is a count of equal-share bins or a vector of increasing inner probabilities strictly between 0 and 1; e is a fastmath quantile estimation strategy (default :legacy).

4.41 quantile range

Two sample quantiles {:quantiles [p q]}, fractions from 0 to 1 with p below q, e.g. {:quantiles [0.05 0.95]}.

4.42 random generator

A fastmath random generator, e.g. (r/rng :mersenne 7); a seeded one draws the same values on every build.

4.43 sample step

How densely a curve is sampled: a positive number of pixels between samples, e.g. 2, or {:count n} - n samples, at least 2, e.g. {:count 50}.

4.44 size range

Two non-negative numbers [min max] in pixels, min at most max, e.g. [2 10].

4.45 solid colour

Any clojure2d colour: a name such as :steelblue, a hex string such as #0072b2, an integer such as 0x0072b2, a vector of channels such as [0 114 178], or (c/color 0 114 178 128) with an alpha.

4.46 span

The range a function is sampled over, [lo hi]: two finite numbers with lo below hi, e.g. [0 10], or two different java.time values.

4.47 text colour

A solid colour, or :contrast.

4.48 variable

A column of wide rows, one axis of a parallel coordinates chart: a keyword, labelled by its name, or a [label accessor] pair, e.g. ["petal length" :petal-length].
