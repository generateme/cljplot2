19.1 tile

A cell per row at its x and y, filled by a mapped colour: numeric (a gradient) or categorical (a palette).

Option Type Default Description
:x (required) a keyword, a function or a categorical marker of one cell x position: categorical (a cell per level) or numeric (cells centred on the values, sized by the smallest gap)
:y (required) a keyword, a function or a categorical marker of one cell y position: categorical (a cell per level) or numeric (cells centred on the values, sized by the smallest gap)
:color (required) a keyword, a function or a categorical marker of one cell fill: numeric (a gradient and colour bar) or categorical (a palette and legend); nil - the NA colour
:size a keyword, a function or a categorical marker of one or nil cell size: each cell shrinks by :cell-scale times its size over the size scale's largest 
(def week-hours (for [[i day] (map-indexed vector ["Mon" "Tue" "Wed" "Thu" "Fri"]) hour (range 8 18)]

Its own option writes the value in each cell (black or white by the fill, the :tile-value text role); the cell shape and outline are the Cell style group:

Option Type Default Description
:value-label true or false or a function false label in each cell: true (the colour value, numbers to 2 decimals) or a function of {:value :x :y} returning the text (nil - none), drawn in black or white by the fill under it 
(plot/render-image (plot/arrange [{:data week-hours
                                   :mapping {:x :hour :y :day :color :visits}
                                   :charts [(chart/tile {:value-label true})]
                                   :scales {:y {:reverse true}}
                                   :labels {:title ":value-label true"}
                                   :legend false}
                                  {:data week-hours
                                   :mapping {:x :hour :y :day :color :visits}
                                   :charts [(chart/tile {:value-label #(when (< 30 (:value %)) "busy")})]
                                   :scales {:y {:reverse true}}
                                   :labels {:title "a function: \"busy\" above 30"}}]
                                 {:columns 2 :widths [1 1.15]})
                   {:width 1000 :height 300})

Shared options: Cell style (:cell :cell-scale :stroke-color :stroke-width :alpha); Data and mapping (:data :mapping); Named theme styles (:theme-style).

19.2 bin2d

A 2D histogram: points counted in rectangular cells, the count (or another measure) as the cell colour.

Option Type Default Description
:x (required) a keyword, a function or a categorical marker of one point x positions (numbers)
:y (required) a keyword, a function or a categorical marker of one point y positions (numbers)
:color nil must be nil (the cell colour is the measure): set it so in the chart's mapping when the plot maps :color 
(plot/render-image {:data faithful
                    :mapping {:x :eruptions :y :waiting}
                    :charts [(chart/bin2d)]
                    :labels {:x "eruption [min]" :y "waiting [min]"}}
                   {:width 600 :height 400})

Its options: the number of cells (or a fastmath estimate), a cell width in data units, the cells’ height / width ratio and what the colour measures:

Option Type Default Description
:bins one of :scott-correlated :scott :freedman-diaconis :cross-validation :shimazaki-shinomoto or a positive integer :scott-correlated cells across the x range (a positive integer), or a fastmath estimate-grid-size method giving a cell area (:binwidth wins)
:binwidth a positive finite number cell size in x data units (log10 units on a :log axis); wins over :bins
:shape a positive finite number the panel's height / width (y span / x span with :aspect :iso), estimated from the plot size and facet layout height / width ratio of the normalized binning space (cells are regular in pixels when it matches the panel)
:measure one of :count :percent :pmf :density :count the cell colour: :count, :percent (of the panel's points), :pmf (share of the panel's points) or :density (count / (n * cell area in data units)) 
(plot/render-image (plot/arrange [{:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:bins 10})]
                                   :labels {:title ":bins 10"}
                                   :legend false}
                                  {:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:binwidth 0.25 :shape 0.5})]
                                   :labels {:title ":binwidth 0.25 :shape 0.5"}
                                   :legend false}
                                  {:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:measure :percent})]
                                   :labels {:title ":measure :percent"}}]
                                 {:columns 3 :widths [1 1 1.3]})
                   {:width 1000 :height 320})

The fastmath estimates of the grid (the default :scott-correlated above) - each picks its own cell count:

(plot/render-image (plot/arrange [{:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:bins :scott})]
                                   :labels {:title ":bins :scott"}
                                   :legend false}
                                  {:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:bins :freedman-diaconis})]
                                   :labels {:title ":bins :freedman-diaconis"}
                                   :legend false}
                                  {:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:bins :cross-validation})]
                                   :labels {:title ":bins :cross-validation"}
                                   :legend false}
                                  {:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:bins :shimazaki-shinomoto})]
                                   :labels {:title ":bins :shimazaki-shinomoto"}
                                   :legend false}]
                                 {:columns 2})
                   {:width 900 :height 600})

The other measures: the share of the panel’s points (:pmf) and the density - the count over n times the cell area (the legend shows the scale):

(plot/render-image (plot/arrange [{:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:measure :pmf})]
                                   :labels {:title ":measure :pmf"}}
                                  {:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/bin2d {:measure :density})]
                                   :labels {:title ":measure :density"}}]
                                 {:columns 2})
                   {:width 900 :height 340})

Shared options: Cell style (:cell :cell-scale :stroke-color :stroke-width :alpha); Data and mapping (:data :mapping); Named theme styles (:theme-style).

19.3 field

A raster of a scalar field: the density of mapped points, gridded :values interpolated, or a function of a point (the Fields group).

Option Type Default Description
:x a keyword, a function or a categorical marker of one or nil x of the points (density) or of the gridded data
:y a keyword, a function or a categorical marker of one or nil y of the points (density) or of the gridded data
:value a keyword, a function or a categorical marker of one or nil the field's value at gridded (x, y) on a full lattice, interpolated (absent - a density of the points)
:color nil must be nil (the colour is the field's value): set it so in the chart's mapping when the plot maps :color 
(plot/render-image (plot/arrange [{:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/field)]
                                   :labels {:title "density of the points"}
                                   :legend false}
                                  {:data volcano
                                   :mapping {:x :column :y :row :value :height}
                                   :charts [(chart/field)]
                                   :labels {:title "gridded :value"}}]
                                 {:columns 2 :widths [1 1.2]})
                   {:width 1000 :height 380})

Its options: the raster’s opacity, or a colour per pixel computed by a function (no field, no colour scale):

Option Type Default Description
:alpha a number in [0 1] 1.0 opacity multiplying the colours' alpha
:pixel-color a function a function of a point [x y] returning each pixel's colour (nil - transparent): a raster over :domain, no grid, colour scale or legend; not with :f 
(plot/render-image (plot/arrange [{:data faithful
                                   :mapping {:x :eruptions :y :waiting}
                                   :charts [(chart/field {:alpha 0.5}) (chart/scatter {:size 3 :color :black})]
                                   :labels {:title ":alpha 0.5, points over it"}
                                   :legend false}
                                  {:charts [(chart/field {:domain {:x [-2 2] :y [-2 2]}
                                                          :pixel-color (fn [[x y]]
                                                                         (when (< (+ (* x x) (* y y)) 3)
                                                                           [(int (* 60 (+ x 2))) 80 (int (* 60 (+ y 2)))]))})]
                                   :labels {:title ":pixel-color - a colour per point"}}]
                                 {:columns 2})
                   {:width 900 :height 380})

19.3.1 Field sources

The Fields group gives the field. A function of a point [x y] sampled over a :domain on a grid of :n points per axis (a coarse grid shows its cells):

(plot/render-image (plot/arrange [{:charts [(chart/field {:f (fn [[x y]] (Math/sin (+ (* x x) (* y y))))
                                                          :domain {:x [-2 2] :y [-2 2]}})]
                                   :labels {:title ":f over :domain"}
                                   :legend false}
                                  {:charts [(chart/field {:f (fn [[x y]] (Math/sin (+ (* x x) (* y y))))
                                                          :domain {:x [-2 2] :y [-2 2]} :n 12})]
                                   :labels {:title ":n 12"}}]
                                 {:columns 2 :widths [1 1.2]})
                   {:width 900 :height 380})

19.4 contour

Level lines (or filled bands) of a scalar field - the same sources as field; categorical groups give a field each.

Option Type Default Description
:x a keyword, a function or a categorical marker of one or nil x of the points (density) or of the gridded data
:y a keyword, a function or a categorical marker of one or nil y of the points (density) or of the gridded data
:value a keyword, a function or a categorical marker of one or nil the field's value at gridded (x, y) on a full lattice, interpolated (absent - a density of the points)
:color a keyword, a function or a categorical marker of one or nil categorical groups, each its own field with lines in its colour (else the lines are coloured by level)
:dash a keyword, a function or a categorical marker of one or nil groups, each its own field with lines in its dash style
:group a keyword, a function or a categorical marker of one or nil groups without a visual aesthetic, each its own field 
(plot/render-image (plot/arrange [{:data volcano
                                   :mapping {:x :column :y :row :value :height}
                                   :charts [(chart/contour)]
                                   :labels {:title "gridded :value"}
                                   :legend false}
                                  {:data iris
                                   :mapping {:x :sepal-length :y :sepal-width :color :species}
                                   :charts [(chart/contour {:levels 6})]
                                   :labels {:title "a density per :color group"}}]
                                 {:columns 2 :widths [1 1.25]})
                   {:width 1000 :height 380})

Its options: the levels (a count or the values), filled bands instead of lines, labels on the lines, one line colour and the opacity:

Option Type Default Description
:color a clojure2d color or :none [69.0 117.0 180.0 255.0]; the theme's, for grouped lines without a mapped colour; ungrouped lines are coloured by level, lines grouped by :color take their group's colour one colour for every line instead of colouring by level (contour's own :color, not the line style's)
:alpha a number in [0 1] 1.0; the theme's; grouped filled contours take half of it opacity multiplying the colours' alpha
:levels integer (1..1000) or vector of a finite number (at least 1) 10 contour levels: a count evenly spread over the range of every sampled value (the ends left out), or a vector of level values
:fill true or false false fill the region at or above each level, each band coloured by its middle value, instead of drawing lines
:labels true or false or a function or nil false line contours only: label each line with its level - true (the number) or a function of {:level v} returning the text (nil - no label) 
(plot/render-image (plot/arrange [{:data volcano
                                   :mapping {:x :column :y :row :value :height}
                                   :charts [(chart/contour {:levels [100 120 140 160 180] :labels true
                                                            :color [40 40 40]})]
                                   :labels {:title ":levels vector, :labels true"}}
                                  {:data volcano
                                   :mapping {:x :column :y :row :value :height}
                                   :charts [(chart/contour {:fill true :levels 8 :alpha 0.8})]
                                   :labels {:title ":fill true :levels 8"}}]
                                 {:columns 2 :widths [1 1.25]})
                   {:width 1000 :height 380})

19.5 correlation

The correlation coefficient r of two variables drawn as one glyph filling the panel - a cell of a correlogram (plot/pairs). Alone it writes r, one line per group.

Option Type Default Description
:x (required) a keyword, a function or a categorical marker of one first variable (numbers)
:y (required) a keyword, a function or a categorical marker of one second variable (numbers)
:color a keyword, a function or a categorical marker of one or nil categorical groups, each a line of the :number glyph in its colour
:group a keyword, a function or a categorical marker of one or nil groups without a visual aesthetic, each a line of the :number glyph 
(plot/render-image {:data iris
                    :mapping {:x :sepal-length :y :petal-length :color :species}
                    :charts [(chart/correlation)]}
                   {:width 450 :height 300})

Its options: the coefficient, the glyph and its colours (by default r on a diverging scale):

Option Type Default Description
:color a clojure2d color or :none [69.0 117.0 180.0 255.0]; grouped shape glyphs: the theme's; ungrouped: r on a diverging scale; :number: the :correlation text role's colour, group lines mapped or black one fixed glyph colour, the :number text's too
:stroke-color :darker or a clojure2d color or :none :darker outline colour: a colour, :none or :darker (the darkened fill)
:stroke-width a non-negative number 1 outline width in pixels
:method one of :pearson :spearman :kendall :pearson correlation coefficient: :pearson, :spearman or :kendall
:glyph one of :number :shade :square :circle :ellipse :pie :number how r is drawn: :number (text, a line per group), :shade (the panel in r's colour), :square / :circle (area ~ |r|), :ellipse (normal contour) or :pie (a disk filled |r|)
